# PriorityIcon

A task's priority (core's `TaskPriority`) as a gauge of three rising bars, filled up to its level: `HIGH` all three in `priority-high` (red), `MEDIUM` two and `LOW` one, both grey (`priority-medium` and `priority-low` are `muted-foreground`), the bars above the level a faint track (the icon's colour at 30%). `NONE` is the track alone, in `muted-foreground`. The bar count carries the level, so only high takes a colour, and every level is the same width, so a column of them lines up. Drawn as SVG, not a Lucide icon. Where a control names priority in general (the toolbar's sort and group, the selection bar, the "+ Add" menu, the row's Priority submenu), it uses Lucide's `ChartNoAxesColumnIncreasing`, the same rising bars. Unlabelled in rows (it still names itself to screen readers, "High priority"); inside a Badge with its word in the properties panel.

`NONE` is no priority, which only a synced task has: its provider has none set (Linear's "No priority") or none DevBrain can read. Sync is the only thing that sets it. It names itself "No priority" and stays neutral, as its group heading does (so do medium and low: only a high group's heading is tinted). No menu offers it: see `PriorityMenu`.
