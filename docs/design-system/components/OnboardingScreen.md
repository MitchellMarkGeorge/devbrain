# OnboardingScreen

The window before a workspace is open (Figma "Splash", "Welcome", "Create workspace" and the Welcome error states): no sidebar, the traffic lights alone in a 48px draggable strip, and one centred column at most 480px wide: the mark (`Logomark`, 40×48; 60×72 pulsing on the splash), the title (30px semibold `foreground-strong`, 38px under the mark) and a 14px `muted-foreground` line, then the content 32px below (a `WorkspaceList`, the Create / Open buttons, the Create workspace card). An optional footer link sits at the window's foot ("What's a workspace?").

**Base UI:** No Base UI part: plain markup.
