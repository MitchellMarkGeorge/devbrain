# EmptyState

Figma's `EmptyState`: an empty page or section. The page's entity icon (20px, `muted-foreground`) in a 40px `secondary` tile with 10px corners, the title (14px medium `foreground-strong`), a one-line description (14px `muted-foreground`), and an optional `sm` default button ("New Task", "Clear Filters"), centred, 16px apart, 24px padding, at most 440px wide. `placement="page"` (the default) centres it 160px under the toolbar.

Copy follows Figma's examples: "No tasks yet", "No notes yet", "No projects yet", "Trash is empty", "No tasks match these filters" (Clear Filters), "Nothing scheduled" (New Event).

**Base UI:** No Base UI part: plain markup.
