# Checkbox

shadcn's Checkbox in the Figma style: Nova's: 16px, 4px corners, an `input` outline over an `input`/30 fill so it is findable at rest; checked fills with `primary`.

- In lists it selects rows for bulk actions. Completing a task is the `StatusIcon`, never this box.

**Base UI:** `Checkbox.Root` and `Checkbox.Indicator`. Styles key off `data-checked` / `data-unchecked`, `data-indeterminate`.
