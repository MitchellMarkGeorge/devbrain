# Field

A shadcn Label over a control with an optional error: 14px medium label, 8px gap, 14px `destructive` error that says how to fix the value.

**Base UI:** `Field.Root`, `Field.Label`, `Field.Control`, `Field.Description`, `Field.Error` (`@base-ui/react/field`). Styles key off `data-invalid`, `data-touched`, `data-dirty`.
