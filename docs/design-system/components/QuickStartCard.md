# QuickStartCard

The first-run Home's "Quick start" cards (Figma "Home — first run"): New task, New note, New project, Bring in your work. A button drawn as a `card` with the `edge` outline and 14px corners, 16px padding: a 16px icon in a 32px `secondary` tile with 8px corners (or provider tiles 6px apart via `QuickStartTiles`), 12px, the name (14px medium `foreground-strong`) over a two-line 12px `muted-foreground` description. Hover strengthens the outline to `border-strong` and lifts the fill. Four sit in a row, 12px apart, under a 12px "Quick start" label.

**Base UI:** No Base UI part: a button.
