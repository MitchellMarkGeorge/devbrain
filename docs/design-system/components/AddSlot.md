# AddSlot

The dashed invitation where something can be added but nothing is yet: "+ Add a task note" on a task page (60px, `size="lg"`), "+ Add a note" and "+ Link a task" in a sheet (40px). A full-width button with a 1px dashed `border-strong` outline, 10px corners, the plus and label in 14px `muted-foreground`, 16px in. Hover fills it with `row-selected` and lifts the label to `foreground`. The board's "Add task" slot is the same idea at the end of a column.
