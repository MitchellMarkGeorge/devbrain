# StepCard

Figma's `StepCard`: one step of the guided start on the first-run Home. A `card` with the `border` outline, 14px corners, 20px padding and 12px gaps: the step number in a 24px `border-strong` ring, the title (16px medium), a two-line 12px description, a 96px preview (`card` with `edge`, 10px corners: provider tiles, a `QuickAddInput`, a note's ghost) and a 28px footer (its button, or "↵ to add it"). Done: a 20px completed `StatusIcon` replaces the number, the title turns `muted-foreground`, the preview dims to 50% and the footer reads "Done · 1 task added".

**Base UI:** No Base UI part: plain markup.
