# AccountStatus

An integration account's state as an outlined 24px pill (8px in on the left, 10px on the right, 6px gap, 12px medium) beside its name:

- `connected`: green filled check, `foreground` label.
- `needs-reconnect`: amber triangle, `health-at-risk` label.
- `off`: slashed circle, `muted-foreground`.
- `coming-later`: clock, `muted-foreground`, dashed outline.

**Base UI:** No Base UI part: a span.
