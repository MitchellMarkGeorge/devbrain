# LinkToolbar

The link editor, 340px wide and 36px tall, 4px under the link or the selection. The same strip as the `FormatToolbar`.

- **Empty**: a link icon, the field "Paste or type a link…", and a ↵ key cap; Enter applies the link.
- **Filled**: the address (cut with "…", still editable), a rule, then Open link and Remove link (unlink) icon buttons.

**Base UI:** `Toolbar` (`Root`, `Input`, `Button`, `Separator`).
