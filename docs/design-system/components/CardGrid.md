# CardGrid

Cards in equal columns: Home's projects and recent notes (12px apart, `gap="sm"`) and the Notes and Projects card views (16px, `gap="md"`). Three columns by default; in compact windows (inside an `AppShell`) two (README "Window sizes"). `singleRow` keeps one row and hides the rest, which the section's "All …" link leads to.

**Base UI:** No Base UI part: a CSS grid.
