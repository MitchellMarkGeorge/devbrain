# BoardCard

A task on the board: the linked event (colour bar) or note (file icon) as a quiet 12px line, the title in 14px, then one 12px line with `PriorityIcon`, subtasks, the project (its folder icon in the project's colour) and the date on the right. A borderless filled card (`card`; `neutral-100` in light, where a borderless card needs a step more to show on white) with 10px corners; on hover it lightens and gains a `border-strong` outline, keyboard focus takes Nova's ring, and completed cards go darker with a dimmed title.
