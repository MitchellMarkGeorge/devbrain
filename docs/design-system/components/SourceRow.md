# SourceRow

One "Use this account for" source inside an `IntegrationCard`: a 60px row with a 16px `muted-foreground` icon and the title (14px medium `foreground-strong`) over the description (12px `muted-foreground`, indented 24px under the title), then an optional button ("Choose Calendars"), the status text (12px `subtle-foreground`; `tone="warning"` amber for paused, `error` red) and the source's `Switch`, 16px apart. `disabled` fades the row to 50% when its account is off.

**Base UI:** No Base UI part: the Switch is the control.
