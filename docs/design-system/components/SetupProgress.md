# SetupProgress

Figma's `SetupProgress`: the first-run Home's setup pill at the top right. A 28px pill outlined in `border`: "Setup" (12px `muted-foreground`), "2 of 3" (12px medium `foreground`), then a 6px dot per step, 4px apart, `foreground` once done and `border-strong` before. Three steps: calendar or Linear, first task, first note.

**Base UI:** No Base UI part: a `progressbar`.
