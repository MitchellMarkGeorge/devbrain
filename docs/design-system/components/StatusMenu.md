# StatusMenu

The menu a row's status icon opens: a "Status" label, then Not started, In progress and Completed with their `StatusIcon`s. The current status is ticked (on the right) and highlighted; the others show their shortcut (`1`, `2`, `3`), which picks them while the menu is open. 200px wide, Nova's menu: `popover`, the `edge` outline, 10px corners, 28px items.

- Also the task right-click menu's Status › submenu (`StatusMenuContent submenu`).
- `ValueMenuContent` draws any single-value picker of this shape; `PriorityMenu` is the other one.
