# Sidebar

shadcn's Sidebar laid out as in Figma's `Sidebar` symbol: 256px on the page colour (`sidebar`) with a `sidebar-border` hairline at its right, 12px side padding, 16px between blocks.

- **Window row** (inside an `AppShell`): 44px, the traffic lights at the left, then the sidebar toggle, back and forward (28px muted icon buttons, 8px apart) at the right.
- **Header:** a 20px `WorkspaceTile`, the workspace name (14px medium `foreground`) and a 12px up-down chevron that opens the `WorkspaceSwitcher` (the row fills with `sidebar-accent` on hover and `accent` while open); then search and new (`SidebarAction`: 28px icon buttons with their shortcut in the tooltip).
- **Items:** every item, in the main navigation and in Recents and Favorites, is the same: 32px, 8px in, 16px icon (or an event's 16px `ColourBar`), 14px `sidebar-foreground` label, 8px corners. Hover fills `sidebar-accent`; the current page takes `sidebar-accent` with a `border-strong` outline drawn inside (so labels never shift). The main navigation's items are 2px apart; Recents and Favorites stack edge to edge under Nova's 32px label (12px medium at 70%), which folds the group away when clicked (its chevron shows on hover); groups fold by default, `collapsible={false}` keeps one open.
- **Footer:** the `SyncStatus` line, then Trash, Settings and Help, pushed to the bottom.

- **Rail** (Figma's `SidebarRail`, `sidebar-rail-width`): on the page colour (`background`) with no hairline, so it and the `WindowBar` above it read as one frame around the page; 8px sides, 12px between blocks with 24px `SidebarSeparator` hairlines between them: the workspace tile, search and new, the pages, then Recents (clock) and Favorites (star) 2px apart, which open 240px popovers listing their items; the footer at the bottom. Every rail item (`RailItem`) is 40×32 with 8px corners: hover fills `sidebar-accent`, the current page adds the `border-strong` outline, and a tooltip at its right names it with its go-to keys ("Tasks G T"). The window controls move to the `WindowBar`. The user can collapse it at any size (⌘\), and it rests collapsed in compact windows (below `breakpoint-medium`).
- **Drawer in compact windows:** expanding the rail there opens the full sidebar as a drawer over the page (`shadow-2xl`, the `backdrop` scrim behind) rather than pushing the page narrower. Picking a page, clicking the scrim or Esc closes it. `AppShell` does this; the sidebar only renders.

- **Collapsing and expanding** slide the width between 256px and the 56px rail in `duration-slow` (250ms, `ease-surface`), and the page beside it widens or narrows with it; the content fades in as it switches layout. The page icons sit 20px in, in both, so they hold still while the width slides. In compact windows the drawer opens with the same motion, widening from the rail over the page (see `AppShell`). Nothing moves under `prefers-reduced-motion`.

**Base UI:** No single Base UI part: shadcn's Sidebar layout built from plain markup, with Base UI `Menu` for the workspace switcher, `Popover` for the rail's Recents and Favorites, `Collapsible` for collapsible groups and `ScrollArea` for the scrolling list. Active items carry `data-active`.
