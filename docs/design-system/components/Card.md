# Card

shadcn's Card, as Nova draws it: a filled `card` ground (`neutral-900` in dark, `neutral-50` in light), the translucent `edge` outline, 14px corners, no shadow, 16px padding and gap; 16px medium title, 14px `muted-foreground` description, optional action on the right.

- `data-size="compact"` (12px padding, Nova's `size=sm`) for the Home summary cards, `ScheduleCard` and `NoteCard`. Settings groups are Cards of rows, divided by `border`. Inside a card, pills stay transparent, fields keep their `input` fill and border, and a segmented control's thumb is `secondary` (`neutral-800` in dark) so it shows on the card.

**Base UI:** No Base UI part: plain markup.
