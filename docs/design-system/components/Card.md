# Card

shadcn's Card, as Nova draws it: `card` ground, the translucent `edge` outline, 14px corners, no shadow, 16px padding and gap; 16px medium title, 14px `muted-foreground` description, optional action on the right.

- `data-size="compact"` (12px padding, Nova's `size=sm`) for the Home summary cards, `ScheduleCard` and `NoteCard`. Settings groups are Cards of rows.

**Base UI:** No Base UI part: plain markup.
