# StatusIcon

A task's status as a 16px icon (12px inside badges): `not-started` circle, `in-progress` activity line, `completed` filled check, `overdue` flag (derived from the due date), `cancelled` slashed circle.

- Colours: `status-*` tokens. Each state has its own shape, so colour is never the only signal.
- In a row, clicking it opens the status menu.
