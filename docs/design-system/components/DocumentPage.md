# DocumentPage

The layout of a document page (a task, a note; Settings and Integrations at `width="settings"`): the top bar (breadcrumb, star, "…" menu) spans the whole page, and the content scrolls under it in a centred column capped at `content-max-width` (720px; 760px for settings), 48px below the bar with 24px side margins. On a wide window the margins grow and the column keeps its width, so moving between a task and its note never shifts the text; menus anchored to the content (the slash menu, pickers under the property pills) move with it. Workspace pages (lists, the board, the calendar) use the full width instead. See "Page widths" in the README.
