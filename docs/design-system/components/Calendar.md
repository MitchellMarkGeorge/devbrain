# Calendar

shadcn's Calendar (react-day-picker), drawn as Figma's mini calendar: 13px tabular numerals in Nova's 28px cells with 8px corners, single-letter weekdays and outside days in `subtle-foreground`, today on a `now-indicator` square with a white number, the selected day on `secondary`.

- In the calendar sidebar and inside date pickers. Weeks start on Monday.

**Base UI:** Base UI has no calendar: keep shadcn's react-day-picker, inside a Base UI `Popover` for date pickers.
