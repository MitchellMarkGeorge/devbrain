# ProjectRow

A project in the Projects list, on the shared 48px `ListRow`: its folder in the project's colour (darkened on white so green and amber keep 3:1), the name, then on the right a status pill (`ProjectStatusIcon` and its label) right-aligned in a 120px column, a 120px `Progress` bar with the percent in 32px, and the date right-aligned in the default 60px, the width of a task row's date, as the task list shows dates: always the date and never relative ("Jul 1"; "Dec 2025" in another year, from `formatListDate`). It is the due date, in `date-today` when it is today and `date-overdue` when it has passed (`dateTone`), or, once the project is completed, the day it was done, uncoloured (the status pill says it is done). Without a date it reads "No date" (`NO_DATE_LABEL`), as an undated task row does. A project synced from Linear (`external`) leads its pills with a `SourcePill` naming the provider ("Linear"), which opens the source's `EntityHoverCard` as a synced task's key does.

`project`: core's `Project` as it is (`ProjectRowData`: `title`, `color`, `status`, `dueDate`, `completedAt`); its colour goes through `resolveColor` (a swatch name or a `#rrggbb`; anything else keeps the grey folder). `stats` (`numOfCompleted`, `totalTasks`: the `stats` each `projects.list` item carries) draws the bar and percent; without it (while it loads) there is no bar. Project health is not shown for now, so every bar is green (`health-on-track`).
