# SwatchPicker

Picks a workspace, project or calendar colour from the six `swatch-*` tokens: 24px squares with 8px corners in a radio group; the chosen one shows a 14px `neutral-950` check and a 2px `foreground` outline offset 2px. Swatches sit 12px apart (Figma draws each in a 32px slot, 4px apart), so the picker is 212px wide in a settings row.
