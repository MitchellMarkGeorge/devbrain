# SectionHeading

Figma's `SectionHeading`: a page section's heading, 24px tall. The title in 14px medium `foreground-strong`, an optional quiet description in 12px `muted-foreground` ("Up next Tomorrow and later this week"), and at the right a 12px `muted-foreground` link with a 12px arrow ("All tasks →", "View calendar →") that lifts to `foreground` on hover. Home's Today, Projects and Recent notes sit 6px under theirs.

**Base UI:** No Base UI part: a heading and a link or button.
