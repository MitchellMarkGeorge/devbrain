# Icon

Lucide icons (shadcn's set) at stroke 1.75 to match the light Bootstrap Icons of the Figma screens, in `currentColor`: 16px for navigation, status and row icons; 12px inside pills and xs buttons; 16px in buttons and menu items, as Nova sizes them. Inactive icons sit in `muted-foreground`; status icons take their status token. An `Icon` keeps its size in a box narrower than itself (`max-width: none`, overriding the reset's `svg { max-width: 100% }`), so a stacked pill's edge clips its icon rather than squeezing it. A menu or other slot that takes an `IconSource` sizes a Lucide component itself: pass `Calendar`, not `<Calendar />`, whose 24px default would be squeezed out of line.
