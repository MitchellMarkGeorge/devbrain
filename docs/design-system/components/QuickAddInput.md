# QuickAddInput

Figma's `QuickAddInput`: the first-run Home's inline quick-add. A 32px field on Nova's input fill with the `input` outline and 10px corners: a 16px plus, the placeholder ("What are you working on today?") and a ↵ `Kbd` at the right. Enter adds what was typed (a task due today) and clears the field. On a `popover` (inside a `SetupPrompt`) set `surface="popover"`, which fills the key with `border-strong`.

**Base UI:** No Base UI part: a native input in a label.
