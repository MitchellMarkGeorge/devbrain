# SetupPrompt

Figma's `SetupPrompt`: a crisp call to action centred over a ghosted Home section on the first-run Home (with `ScheduleCardSkeleton` / `ProjectCardSkeleton` behind it). A `popover` card with the `edge` outline, `shadow-md` and 14px corners, 10px padding (12px at the left), 12px gaps: an icon in a 32px `secondary` tile (or a `ProviderTile`), a title (14px medium) over a 12px description, then its actions ("Connect Google Calendar" and a ghost "Skip"; "New Note"). The task kind holds a `QuickAddInput`, "or" and "Connect Linear" alone.

**Base UI:** No Base UI part: plain markup.
