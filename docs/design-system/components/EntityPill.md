# EntityPill

The chip every relation uses: in task rows, in the `PropertyRow` lines on task and project pages, and on note headers. It opens the linked item on click: `project` (folder icon in the project's colour), `note` (file icon), `task` (its status icon), `parent` (a subtask's parent: a `muted-foreground` corner arrow, then its status icon), `event` (a bar in the calendar's colour). Property values use the same pill with their own glyph (`glyph`): status, priority, dates, a project's progress, "+ Add" and a note's linked-tasks summary (`circle-check`, "3 tasks · 2 in progress").

- shadcn's outline badge with a `border` outline, on `pill-fill`: none in dark, so the pill is its outline on the page, a `card`, a sheet or a hovered or selected row alike (it was the page colour, `neutral-950`, until Nov 2026, which set a dark chip into cards; transparent keeps a card with several pills calm); white in light, a chip on grey cards and hovered rows, where a transparent pill's outline would match the surface. Pointing at it fills it with `pill-fill-hover` (`accent` at 60% in dark, `accent` in light), strengthens the outline to `border-strong` (the board card hover outline) and lifts the label from `muted-foreground` to `foreground`. At rest every label stays muted. The same rule in both themes.
- Pointing at a pill for about 400ms opens its `EntityHoverCard`, a preview of the item; clicking still opens it.
- `color` sets a project's icon or an event's bar to one of the six `swatch-*` colours; a project with no colour keeps a grey icon. Every label sits in `muted-foreground`, events included: the icon or bar says what the link is, so no kind of link outweighs another in a row. Detail pages drop prefixes ("Linked to", "Subtask of"): the icon says what the link is.
