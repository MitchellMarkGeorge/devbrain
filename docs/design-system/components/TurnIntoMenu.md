# TurnIntoMenu

The block types a selection can become, opened from the `FormatToolbar`'s block button, 220px: the "Turn into" label, then Text, Heading 1–3, Bulleted list, Numbered list, To-do list, Code and Quote with their 16px icons, the current one ticked on the right, then a separator and Task. `BLOCK_TYPES` lists the types with their icons and Markdown shortcuts, shared with the `SlashMenu`.

**Base UI:** `Menu` (`RadioGroup`, `RadioItem`, `RadioItemIndicator`) inside DevBrain's `DropdownMenuContent`.
