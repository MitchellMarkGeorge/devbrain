Press <kbd>?</kbd> in DevBrain, or the **Help** button at the bottom of the sidebar, to see these
in the app. On Windows and Linux, <kbd>⌘</kbd> is <kbd>Ctrl</kbd>, and <kbd>⌘⌫</kbd>
is <kbd>Ctrl Backspace</kbd>.

## Everywhere

| Keys                      | Action                                                      |
| ------------------------- | ----------------------------------------------------------- |
| <kbd>⌘K</kbd>             | [Search](/docs/search/)                                     |
| <kbd>C</kbd>              | New task                                                    |
| <kbd>N</kbd>              | New note                                                    |
| <kbd>G</kbd> <kbd>H</kbd> | Go to Home                                                  |
| <kbd>G</kbd> <kbd>T</kbd> | Go to Tasks                                                 |
| <kbd>G</kbd> <kbd>P</kbd> | Go to Projects                                              |
| <kbd>G</kbd> <kbd>N</kbd> | Go to Notes                                                 |
| <kbd>G</kbd> <kbd>C</kbd> | Go to Calendar                                              |
| <kbd>G</kbd> <kbd>I</kbd> | Go to Integrations                                          |
| <kbd>G</kbd> <kbd>S</kbd> | Go to Settings                                              |
| <kbd>G</kbd> <kbd>X</kbd> | Go to Trash                                                 |
| <kbd>?</kbd>              | Keyboard shortcuts                                          |
| <kbd>⌘\\</kbd>            | Show or hide the sidebar                                    |
| <kbd>⌘Z</kbd>             | Undo the last move to the trash, and other undoable actions |
| <kbd>⌘D</kbd>             | Duplicate the task or note you're on                        |
| <kbd>⌘,</kbd>             | Settings                                                    |
| <kbd>⌘O</kbd>             | Open a workspace folder                                     |
| <kbd>⌘⇧S</kbd>            | Sync now                                                    |

For the "Go to" shortcuts, press the two keys one after the other. Single-letter shortcuts don't
apply while you're typing in a field.

## Lists

In the lists of tasks, projects, notes and the trash:

| Keys                                   | Action                              |
| -------------------------------------- | ----------------------------------- |
| <kbd>↓</kbd> <kbd>↑</kbd>              | Move down or up                     |
| <kbd>Home</kbd> <kbd>End</kbd>         | First or last                       |
| <kbd>Enter</kbd>                       | Open                                |
| <kbd>→</kbd> <kbd>←</kbd>              | Show or hide a task's subtasks      |
| <kbd>X</kbd>                           | Select                              |
| <kbd>Esc</kbd>                         | Clear the selection                 |
| <kbd>S</kbd>                           | Change the status                   |
| <kbd>1</kbd> <kbd>2</kbd> <kbd>3</kbd> | Not started, In progress, Completed |
| <kbd>F</kbd>                           | Favorite                            |
| <kbd>⌘⌫</kbd>                          | Move to trash                       |

With nothing selected, these act on the focused row; with a selection, on every selected item.

## On the board

| Keys                      | Action                          |
| ------------------------- | ------------------------------- |
| <kbd>Space</kbd>          | Pick up a card, or drop it      |
| <kbd>←</kbd> <kbd>→</kbd> | Move the card to another column |
| <kbd>Esc</kbd>            | Put the card back               |

## In dialogs and search

| Keys                              | Action                                          |
| --------------------------------- | ----------------------------------------------- |
| <kbd>⌘ Enter</kbd>                | Create (in a New task, project or event dialog) |
| <kbd>Enter</kbd> / <kbd>Esc</kbd> | Save or undo a title you're editing             |
| <kbd>Tab</kbd> / <kbd>⇧ Tab</kbd> | Next or previous type filter in search          |

## In the editor

| Keys               | Action                     |
| ------------------ | -------------------------- |
| <kbd>/</kbd>       | Block menu                 |
| <kbd>@</kbd>       | Link a task, note or event |
| <kbd>⌘B</kbd>      | Bold                       |
| <kbd>⌘I</kbd>      | Italic                     |
| <kbd>⌘U</kbd>      | Underline                  |
| <kbd>⌘⇧X</kbd>     | Strikethrough              |
| <kbd>⌘E</kbd>      | Inline code                |
| <kbd>⌘K</kbd>      | Link the selected text     |
| <kbd>⇧ Enter</kbd> | Line break                 |
| <kbd>⌘⇧V</kbd>     | Paste as plain text        |
